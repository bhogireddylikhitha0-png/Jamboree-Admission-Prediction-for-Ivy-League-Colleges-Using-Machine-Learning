# Jamboree-Admission-Prediction-for-Ivy-League-Colleges-Using-Machine-Learning

Problem Statement

The objective of this project is to predict the probability of admission to Ivy League colleges using Machine Learning. The model uses factors such as GRE score, CGPA, and research experience to estimate admission chances.

Project Description

This project analyzes historical admission data and builds a Machine Learning model to predict admission probability. The project includes data cleaning, preprocessing, Exploratory Data Analysis (EDA), feature engineering, model training, and model evaluation.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Machine Learning

Features Used

- GRE Score
- CGPA
- Research Experience
- Other admission-related features

Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Admission Prediction

Models Used

- Linear Regression
- XGBoost

Evaluation Metrics

- MAE
- RMSE
- R² Score

Conclusion

This project demonstrates how Machine Learning can be used to analyze admission data and predict the probability of admission based on academic and profile-related factors.
